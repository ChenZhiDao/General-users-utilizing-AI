# 普通人如何使用 AI

一份写给「不写代码的人」的 AI 使用手册：不讲原理，只讲**今天就能用上**的方法。

## 这个仓库是什么

- 面向：不会编程、但想让 AI 真正帮上忙的普通用户（上班族、学生、个体户、家长）
- 内容：能直接照抄的话术模板、真实场景、常见坑
- 原则：**不吹能力，只讲验证过的用法**

## 目录（持续更新）

| 章节 | 内容 |
|---|---|
| `01-起步` | 选哪个 AI、免费额度够不够、怎么问第一句 |
| `02-提问` | 万能四段式模板：目标 / 约束 / 验收 / 追加指令 |
| `03-场景` | 写材料、做表格、查资料、学新东西、处理图片和 PDF |
| `04-避坑` | 一本正经胡说、隐私泄露、把 AI 当搜索引擎的错 |
| `05-进阶` | 让它动手（agent）、自动化、把重复流程存下来 |

## 一句话总结

> 别问「这件事怎么做」，直接说「做这件事，做完给我看结果」。

## 使用方式

- 想快速上手：从 `01-起步` 读起，20 分钟能读完
- 想解决具体问题：直接看 `03-场景`，找和你情况最像的那一条
- 欢迎提 Issue 补充你的真实用法
