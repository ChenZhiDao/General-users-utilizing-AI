# Obsidian 使用指南（每步含示例）

> 适用版本：Obsidian 1.x（Windows / macOS / Linux / 手机端通用，快捷键以 Windows 为例，macOS 将 `Ctrl` 换成 `Cmd`）。
> 核心理念：笔记 = 本地 Markdown 文件；知识 = 笔记之间的双向链接网络。

---

## 1. 创建仓库（Vault）

仓库就是一个普通文件夹，Obsidian 把里面所有 `.md` 文件当作笔记。

**操作步骤**

1. 打开 Obsidian → 点击「创建新仓库」
2. 填写仓库名称，选择存放位置
3. 点击「创建」

**示例**

```text
仓库名称：我的知识库
存放位置：D:\Notes\我的知识库
```

创建后文件夹里会出现一个隐藏的 `.obsidian` 目录（存放设置和插件），你的笔记和它平级存放：

```text
D:\Notes\我的知识库\
├── .obsidian\          ← 配置目录，不要手动改
├── 日记\
├── 读书笔记\
├── 项目\
└── 欢迎.md
```

**建议**：一个主题域用一个仓库即可，不要按"工作/生活"拆成多个仓库，跨库无法互相链接。

---

## 2. 认识界面

打开仓库后，界面分四块：

| 区域 | 位置 | 作用 |
|---|---|---|
| 文件列表 | 左侧栏 | 浏览文件夹和笔记 |
| 编辑区 | 中间 | 写笔记的地方 |
| 侧边面板 | 右侧栏 | 反向链接、大纲、标签 |
| 命令面板 | `Ctrl + P` 呼出 | 搜索并执行任何功能 |

**示例：用命令面板做三件事**

按 `Ctrl + P`，分别输入：

```text
输入「图谱」   → 打开关系图谱
输入「日记」   → 打开/创建今天的日记
输入「切换」   → 找到「切换实时预览/源码模式」
```

记不住任何功能在哪时，`Ctrl + P` 搜关键词就行。

## 3. 新建笔记与基础 Markdown 写作

**操作步骤**

1. 按 `Ctrl + N` 新建笔记
2. 第一行输入标题（Obsidian 默认用文件名作标题）
3. 直接书写 Markdown，实时预览模式下边写边渲染

**示例：新建一篇名为 `Python 装饰器.md` 的笔记，内容如下**

`````markdown
# Python 装饰器

装饰器是一个**接收函数并返回新函数**的函数，本质是语法糖。

## 最小例子

```python
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log
def hello():
    print("hello")

hello()   # 输出：调用 hello → hello
```

## 要点

- `@log` 等价于 `hello = log(hello)`
- 多个装饰器==从下往上==依次应用
- 带参数的装饰器需要再包一层函数

> 参考：[[函数式编程]]、[[Python 闭包]]
`````

**常用语法速查（每项都可立即试）**

```markdown
**加粗**          → 加粗
*斜体*            → 斜体
==高亮==          → 高亮（Obsidian 扩展语法）
~~删除线~~        → 删除线
- 无序列表项
1. 有序列表项
- [ ] 待办未完成
- [x] 待办已完成
> 引用文字
`行内代码`
[外部链接](https://obsidian.md)
![图片](图片路径.png)
| 表头1 | 表头2 |
|---|---|
| 单元格 | 单元格 |
```

**常用编辑快捷键**

| 快捷键 | 功能 |
|---|---|
| `Ctrl + B` | 加粗选中文字 |
| `Ctrl + I` | 斜体 |
| `Ctrl + E` | 切换编辑/阅读视图 |
| `Ctrl + K` | 插入链接 |
| `Ctrl + Enter` | 勾选/取消当前待办 |

## 4. 双向链接（Obsidian 的灵魂）

**操作步骤**

1. 在正文输入 `[[`，弹出笔记搜索框
2. 输入关键词，回车选中目标笔记
3. 目标笔记不存在也可以直接回车——点击链接时才创建它

**示例 1：基本链接与别名**

```markdown
今天学了 [[Python 装饰器]]，它依赖 [[Python 闭包]] 的知识。

链接显示自定义文字：[[Python 装饰器|装饰器详解]]
链接到笔记内某个标题：[[Python 装饰器#最小例子]]
```

**示例 2：查看反向链接**

打开 `Python 闭包.md`，右侧面板「反向链接」会自动列出：

```text
反向链接（1）
└── Python 装饰器.md
    "……它依赖 [[Python 闭包]] 的知识。"
```

这就是"双向"：你只写了 A→B，B 自动知道 A 引用了它。

**示例 3：嵌入整篇笔记或某个段落**

在链接前加 `!` 表示嵌入（内容直接显示在当前笔记里）：

```markdown
![[Python 装饰器#最小例子]]     ← 只嵌入"最小例子"这一节
![[会议记录 2026-11-18]]        ← 嵌入整篇笔记
![[架构图.png]]                 ← 嵌入图片
```

## 5. 标签与属性（Properties）

### 5.1 标签

**操作**：正文任意位置写 `#标签名`，支持 `/` 嵌套。

**示例**

```markdown
#学习/编程 #状态/进行中

今天整理了装饰器的笔记。
```

点击标签或打开右侧「标签面板」，可以看到所有带该标签的笔记。

**标签 vs 链接怎么选**：标签适合"状态、类型"这类横切分类（`#待读`、`#读书笔记`）；链接适合"概念实体"（`[[Python 装饰器]]`）。概念优先用链接，因为链接能承载内容和反向关系。

### 5.2 文档属性（Frontmatter）

**操作**：在笔记最顶部输入 `---` 回车，进入属性编辑区（或按 `Ctrl + ;`）。

**示例：给读书笔记加属性**

```markdown
---
书名: 流畅的Python
作者: Luciano Ramalho
评分: 5
状态: 在读
开始日期: 2026-11-01
tags:
  - 读书笔记
  - 学习/编程
---

# 《流畅的Python》读书笔记
……
```

属性是结构化数据，后面第 12 步的 Dataview 插件可以直接查询它们。

## 6. 搜索与快速跳转

**三个入口，按频率排序：**

1. `Ctrl + O`：按文件名快速打开笔记（日常最高频）
2. `Ctrl + Shift + F`：全库内容搜索
3. `Ctrl + P`：搜索功能命令

**示例 1：快速跳转**

按 `Ctrl + O` 输入 `zsq`（拼音首字母需插件支持，默认输英文/中文片段）：

```text
输入「装饰」 → 命中 Python 装饰器.md → 回车打开
```

**示例 2：搜索运算符**

在 `Ctrl + Shift + F` 搜索框输入：

```text
path:"读书笔记" 装饰器        ← 只在读书笔记文件夹里搜"装饰器"
tag:#状态/进行中              ← 搜所有进行中的笔记
"闭包" -装饰器                ← 含"闭包"但不含"装饰器"
line:(python 装饰器)          ← 两个词出现在同一行
```

**示例 3：把搜索结果嵌入笔记**

````markdown
```query
tag:#读书笔记 path:"读书笔记"
```
````

这段代码块会在笔记里渲染成一个实时搜索框，结果自动更新。

## 7. 关系图谱（Graph View）

**操作**：`Ctrl + P` → 输入「图谱」→ 打开全局图谱；笔记右上角更多菜单可打开「局部图谱」。

**示例：让图谱长出来**

新建三篇互相链接的笔记后，图谱显示：

```text
Python 装饰器 ──── Python 闭包
      │
      └────────── 函数式编程
```

**实用设置（图谱左上角设置图标）**

- 过滤器输入 `path:"读书笔记"` → 只看读书笔记子图
- 开启「箭头」→ 显示链接方向
- 分组：新建分组 `tag:#状态/进行中` 并设为绿色 → 进行中的笔记一眼可辨

**局部图谱示例**：打开 `Python 闭包.md` 的局部图谱，深度设为 2，能看到"装饰器 → 闭包 → 闭包引用的其他概念"两层关系，适合梳理某个主题的上下文。

## 8. 日记（Daily Notes）

**操作步骤**

1. 设置 → 核心插件 → 开启「日记」
2. 设置 → 日记 → 配置：
   - 日期格式：`YYYY-MM-DD`
   - 新建位置：`日记`
   - 模板文件：`模板/日记模板.md`（模板见第 9 步）
3. 点左侧日历图标或 `Ctrl + P` 搜「打开今天的日记」

**示例：2026-11-18 的日记 `日记/2026-11-18.md`**

```markdown
# 2026-11-18 周三

## 今日待办
- [x] 学习装饰器并整理笔记 → [[Python 装饰器]]
- [ ] 读完《流畅的Python》第 7 章
- [ ] 复习 [[Python 闭包]]

## 速记
- 想法：装饰器可以用来做接口耗时统计，试写到 [[项目/接口监控]] 里
- 会议：和导师约了周五讨论，见 [[会议记录 2026-11-20]]

## 复盘
今天最大的收获是理解了 @ 语法糖的本质。
```

日记的价值：所有零散想法先扔进当天日记，用链接指向正式笔记，日记成为"入口"，正式笔记成为"沉淀"。

## 9. 模板（Templates）

**操作步骤**

1. 建一个 `模板` 文件夹
2. 设置 → 核心插件 → 开启「模板」；设置 → 模板 → 模板文件夹位置填 `模板`
3. 在任意笔记中 `Ctrl + P` → 「插入模板」

**示例 1：日记模板 `模板/日记模板.md`**

```markdown
# {{date:YYYY-MM-DD}} {{date:dddd}}

## 今日待办
- [ ]

## 速记


## 复盘

```

插入时 `{{date}}` 自动替换为当天日期，`{{time}}` 替换为当前时间，`{{title}}` 替换为笔记名。

**示例 2：读书笔记模板 `模板/读书笔记.md`**

```markdown
---
书名: {{title}}
作者:
评分:
状态: 想读
tags:
  - 读书笔记
---

# 《{{title}}》

## 一句话总结


## 核心观点
1.

## 与我的关联
- 可以应用到 [[]]

## 金句摘录
>
```

新建笔记命名为 `流畅的Python`，插入模板后属性里的书名自动填好。

**示例 3：会议记录模板 `模板/会议记录.md`**

```markdown
---
日期: {{date:YYYY-MM-DD}}
参会人:
tags:
  - 会议
---

# 会议：{{title}}

## 议题


## 结论与决定
1.

## 行动项
- [ ] 事项 @负责人 截止 YYYY-MM-DD
```

## 10. 白板（Canvas）

Canvas 是无限画布，可以把笔记卡片、图片、网页摆在一起自由连线，适合头脑风暴和梳理结构。

**操作步骤**

1. `Ctrl + P` → 「新建白板」
2. 从左侧文件列表把笔记**拖进画布**（成为卡片）
3. 双击空白处创建文本卡片；拖动卡片边缘的连接点画箭头

**示例：梳理"Python 学习路线"白板**

```text
┌──────────────┐      ┌──────────────┐
│ Python 基础   │ ───→ │ Python 闭包   │
└──────────────┘      └──────┬───────┘
                             │
                             ▼
                      ┌──────────────┐      ┌──────────────┐
                      │ Python 装饰器 │ ───→ │ 项目/接口监控  │
                      └──────────────┘      └──────────────┘
```

画布保存为 `.canvas` 文件（同样是本地开放格式），卡片里的笔记双击即可跳转编辑。

## 11. 附件、图片与导出

**示例 1：粘贴图片**

截图后直接在笔记里 `Ctrl + V`，图片自动存入仓库并生成：

```markdown
![[Pasted image 20261118153000.png]]
```

建议先到 设置 → 文件与链接 → 「附件默认存放路径」设为 `附件` 文件夹，保持根目录整洁。

**示例 2：调整图片大小**

```markdown
![[架构图.png|600]]      ← 宽度 600 像素
![[架构图.png|600x400]]  ← 宽 600 高 400
```

**示例 3：导出 PDF**

打开笔记 → 右上角「更多选项」(⋮) → 「导出为 PDF」，可选页面大小和是否包含文件名。

**示例 4：拖拽引用文件**

把仓库外的 PDF 拖进笔记会复制入库并生成链接；按住 `Ctrl` 拖拽则生成 `file://` 外部链接（不复制）。

## 12. 第三方插件进阶（以 Dataview 为例)

**操作步骤**

1. 设置 → 第三方插件 → 关闭「安全模式」
2. 浏览 → 搜索 `Dataview` → 安装并启用

Dataview 把整个仓库当数据库，用类 SQL 语法查询笔记属性。

**示例 1：列出所有在读的书**

在任意笔记中写入：

````markdown
```dataview
TABLE 作者, 评分, 开始日期
FROM #读书笔记
WHERE 状态 = "在读"
SORT 开始日期 DESC
```
````

渲染结果（自动实时更新）：

| 文件 | 作者 | 评分 | 开始日期 |
|---|---|---|---|
| 流畅的Python | Luciano Ramalho | 5 | 2026-11-01 |

**示例 2：汇总所有未完成待办**

````markdown
```dataview
TASK
FROM "日记"
WHERE !completed
```
````

**示例 3：本周创建的笔记清单**

````markdown
```dataview
LIST
WHERE file.cday >= date(today) - dur(7 days)
SORT file.cday DESC
```
````

**其他值得了解的插件（按需再装）**

| 插件 | 用途 | 典型场景 |
|---|---|---|
| Calendar | 日历视图点选日记 | 快速回顾某天 |
| Templater | 比核心模板更强的动态模板 | 自动执行 JS、弹出输入框 |
| Excalidraw | 手绘风格图表嵌入笔记 | 画架构草图 |
| Kanban | 看板 | 项目管理 |

**原则**：先用一两周原生功能，遇到具体痛点再找插件，避免一上来装几十个。

## 13. 多设备同步

| 方案 | 费用 | 适合人群 |
|---|---|---|
| Obsidian Sync（官方） | 付费 | 想要最省心、端到端加密、版本历史 |
| iCloud | 免费 | 苹果全家桶（Mac + iPhone） |
| OneDrive / 坚果云 WebDAV | 免费/低成本 | Windows + 安卓 |
| Git + 插件 | 免费 | 程序员，想要版本管理 |

**示例 1：iCloud 方案（苹果设备）**

把仓库建在 `iCloud Drive/Obsidian/` 下，iPhone 装 Obsidian App → 「打开文件夹作为仓库」→ 选同一目录即可。

**示例 2：Git 方案（Windows）**

```bash
cd D:\Notes\我的知识库
git init
git add .
git commit -m "初始化知识库"
git remote add origin <你的私有仓库地址>
git push -u origin main
```

再安装社区插件 `Obsidian Git`，设置自动提交间隔（如每 30 分钟），手机端用 Working Copy（iOS）或 Termux（安卓）拉取。

**注意**：无论哪种方案，同一时间尽量只在一台设备上编辑，减少冲突；`.obsidian/workspace.json` 记录窗口布局，多设备同步时可加入忽略列表。

## 14. 完整实战示例：从零搭建一个学习知识库

把前面所有步骤串起来，走一遍真实流程。

**第 1 天：搭骨架**

1. 创建仓库 `我的知识库`（第 1 步）
2. 建文件夹：`日记`、`读书笔记`、`概念`、`项目`、`模板`、`附件`（第 1 步）
3. 开启核心插件：日记、模板（第 8、9 步）
4. 放入三个模板：日记模板、读书笔记模板、会议记录模板（第 9 步）

**第 2 天：日常输入**

早上打开日记（`Ctrl + P` → 日记），记录：

```markdown
## 今日待办
- [ ] 读《流畅的Python》第 7 章：装饰器与闭包

## 速记
- 装饰器 = 闭包 + 语法糖？整理成 [[Python 装饰器]]
```

读书时新建 `读书笔记/流畅的Python.md`，插入读书笔记模板（第 9 步），边读边把概念链接出去：

```markdown
## 核心观点
1. 装饰器在==导入时==执行，被装饰函数在==调用时==执行 → [[Python 装饰器]]
2. 闭包让自由变量跨调用存活 → [[Python 闭包]]
```

**第 3 天：沉淀概念**

点开日记里的红色链接 `[[Python 装饰器]]` 创建概念笔记，写下第 3 步示例中的完整内容，并反向链接到 `[[流畅的Python]]`。

**第 7 天：回顾整理**

1. 打开全局图谱（第 7 步），发现 `Python 闭包` 被 3 篇笔记引用 → 说明是核心概念，值得完善
2. 新建一篇汇总笔记 `Python 学习总览.md`，用 Dataview 自动列出所有概念（第 12 步）：

````markdown
```dataview
LIST
FROM #学习/编程 AND "概念"
SORT file.name ASC
```
````

3. 用 Canvas 把"基础 → 闭包 → 装饰器 → 项目"连成学习路线图（第 10 步）
4. 配置同步，手机端随时查看（第 13 步）

至此形成一个闭环：**日记速记 → 链接沉淀 → 图谱回顾 → 汇总输出**。

## 16. 新手常见问题

1. **笔记该放哪个文件夹？** 先别纠结，随手放 + 多用链接，结构会自然涌现；文件夹只用于大类（日记/模板/附件）。
2. **`[[]]` 和 `#标签` 重复吗？** 不重复：链接是"知识实体"，标签是"状态/类型"，各司其职（见第 5 步）。
3. **删除笔记链接会断吗？** 设置 → 文件与链接 → 开启「自动更新内部链接」，重命名/移动笔记时所有链接自动修正。
4. **数据会被锁死在 Obsidian 里吗？** 不会。全部是本地 `.md` 纯文本，用记事本都能打开，随时可迁移。
5. **要不要买 Sync？** 单设备不需要；多设备先用免费方案试，冲突频繁再考虑官方 Sync。
